# danielrdg.github.io

Static bilingual (EN/PT) portfolio for [danielrdg](https://github.com/danielrdg), published with GitHub Pages. Plain HTML, CSS and ES modules: no build step, no dependencies. The résumé is readable without JavaScript; there are a few things to find if you poke around.

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Tests

```bash
npm test
```

Uses the Node built-in test runner (Node >= 20). No packages to install.

## Open Graph image

`assets/img/og.png` is generated by a script (requires [Pillow](https://pypi.org/project/pillow/)):

```bash
python3 tools/make_og.py assets/img/og.png
```
